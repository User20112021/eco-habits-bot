# Eco Habits Tracker Bot (6В/6Г)

Это простой Telegram-бот для личных сообщений:
- каждый вечер в 18:00 UTC присылает чек-ин
- ученик отмечает эко-привычки кнопками
- есть статистика: личная (📊), класса (🙋), школы (🏫)
- хранит данные в SQLite файле `eco_tracker.db`

## 1) Создайте бота в Telegram (BotFather)
1. Откройте @BotFather
2. Команда: /newbot
3. Скопируйте токен (BOT_TOKEN)

## 2) Запуск на компьютере (самый простой способ)
### Установите Python 3.11+ 
Проверьте:
- Windows: `py -V`
- macOS/Linux: `python3 -V`

### Скачайте файлы проекта
В этой папке должны быть:
- bot.py
- requirements.txt

### Установите зависимости
В папке проекта:
- Windows:
  - `py -m pip install -r requirements.txt`
- macOS/Linux:
  - `python3 -m pip install -r requirements.txt`

### Укажите токен и запустите
**Вариант A (безопаснее): через переменную окружения**
- Windows (PowerShell):
  - `$env:BOT_TOKEN="ВАШ_ТОКЕН"`
  - `py bot.py`
- macOS/Linux:
  - `export BOT_TOKEN="ВАШ_ТОКЕН"`
  - `python3 bot.py`

**Вариант B (не рекомендуется): вставить токен в код**
- Можно, но токен лучше не хранить в открытом виде.

## 3) Как ученикам начать
1. Ученик открывает бота и жмёт /start
2. Выбирает класс (6В или 6Г)
3. Пользуется кнопками:
   - ✅ Отметить сегодня
   - 📊 Моя статистика
   - 🙋 Статистика класса
   - 🏫 Статистика школы

## 4) Частые вопросы
### Бот не пишет вечером
Бот должен быть запущен в этот момент (на компьютере/сервере).

### Ученику не приходит сообщение
Ученик должен один раз нажать /start — Telegram не позволяет ботам писать первым.

## 5) Настройки времени (по желанию)
Можно изменить через переменные окружения:
- BOT_TZ
- BOT_PING_HOUR
- BOT_PING_MINUTE

Пример (Linux/macOS):
`export BOT_PING_HOUR="18"`
